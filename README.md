# Винная подборка: Streamlit

Локальное приложение для модели из ДЗ-3. Интерпретатор: **Python 3.13.16**.

## Запуск отдельной папки

Из корня клонированного репозитория:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1
```

Откройте http://localhost:8501. В Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.

Рядом с `app.py` должны лежать `ui_helpers.py`, `model.joblib`, `config.json`, `test.csv`. Пути определяются от `app.py`: приложение можно запускать из другой директории. Модель уже обучена, приложение не обучает её повторно и не скачивает данные. Не заменяйте `model.joblib` файлом из неизвестного источника: загрузка joblib может выполнять код.

## Возможности

- **Одно вино:** 11 числовых параметров и переключатель красное/белое. Диапазоны и медианы взяты из `test.csv`.
- **Модельные метрики:** матрица ошибок, precision, recall, F1, ROC- и PR-кривые с точкой текущего порога.
- **Пакетное предсказание:** CSV UTF-8 с запятыми, 12 признаков, без `target`. Пример можно скачать в приложении. Результат содержит вероятность `probability` и метку `prediction`.
- **Что выучила модель:** отсортированные коэффициенты после масштабирования.

Порог на боковой панели общий для всех вкладок и первоначально берётся из `config.json`. Правило рекомендации: `probability >= threshold`. Нулевые знаменатели метрик дают 0. Порог в приложении позволяет изучать поведение модели; повторно подбирать его на тесте нельзя.

CSV с пропущенными, лишними или повторяющимися столбцами, нечисловыми значениями, NaN/inf, пустыми данными либо `is_red` вне {0,1} отклоняется с пояснением. Порядок корректных столбцов может быть любым.

## Кеширование

`st.cache_resource` хранит один экземпляр модели для сервера. `st.cache_data` возвращает копии таблиц и массива тестовых вероятностей, защищая кеш от случайных изменений. Аргумент `_model` не хешируется; версия файла модели включена в ключ кеша вероятностей. Движение порога меняет сравнение и метрики, но не вызывает повторный `predict_proba` для тестовой выборки. Без декоратора `joblib.load` перечитывал бы модель при каждом перезапуске скрипта.

Документация: [cache_resource](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_resource), [cache_data](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_data).

## Проверки и публикация

Проверены все вкладки, пороги 0 и 1, кеширование и загрузка CSV. Для 10 вин скачанные прогнозы совпали с локальной моделью. Дополнительные тесты находятся в папке `tests/` полного учебного архива, в этот репозиторий они не включены.

Для Community Cloud укажите этот репозиторий, ветку `main`, путь `app.py` и Python 3.13. Файл `requirements.txt` находится в корне рядом с приложением. В репозитории находятся только семь файлов приложения; ноутбук, исходные данные и дополнительные тесты передаются отдельно в учебном архиве.
